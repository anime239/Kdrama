# kdrama

Cloudstream 3 extension repository for streaming Korean dramas and movies.

## Installation

* **Direct Install:** [Install kdrama](https://recloudstream.github.io/redirect?url=https://raw.githubusercontent.com/anime239/Kdrama/builds/repo.json)
* **ShortCode:** `kdrama`
* **Repository URL:**
  ```text
  https://raw.githubusercontent.com/anime239/Kdrama/builds/repo.json
  ```

### How to Add Manually
1. Open **Cloudstream** and go to **Settings → Extensions**.
2. Tap **Add repository**.
3. Enter `kdrama` (or paste the full Repository URL above) and tap **Add repository**.
4. Open the **kdrama** repository and tap **Download** on the extension.
